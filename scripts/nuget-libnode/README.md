# Description

libNode is Node.js **$nodeVersion$** built as a shared library.
It can be used from different programming environments using the C-based Node-API and the Node.js embedding API.

The package version follows v8-jsi versioning and is not the Node.js version.

See the [Node.js $nodeVersion$ release notes](https://github.com/nodejs/node/releases/tag/v$nodeVersion$).
